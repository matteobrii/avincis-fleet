# Avincis Fleet

Applicazione web per la gestione della flotta elicotteri Avincis - Base di Colico.

## Descrizione
Pannello di controllo per il monitoraggio degli aeromobili, 
pianificazione manutenzioni e gestione documentazione tecnica.

## Contenuto
- `index.html` – Interfaccia principale dell'applicazione
- `avincis_backup_2026-04-28.json` – Backup dati fleet

## Utilizzo
Aprire `index.html` nel browser per accedere al pannello.
